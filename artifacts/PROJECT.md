# Javier Milei

Presidential landing page for Javier Milei, President of Argentina.

**Access:** public. No auth, no database.

## Features
- Inauguration hero (Casa Rosada balcony)
- Record stats (inflation, surplus, GDP)
- Four-pillar program (fiscal, money, state, West)
- 2023–2026 timeline
- Short bio and a local-only dispatch form

## Code
- `src/routes/index.tsx` — page composition
- `src/components/landing/*` — sections
- `src/lib/content.ts` — copy
- `public/images/` — portrait, inauguration, podium, Casa Rosada
